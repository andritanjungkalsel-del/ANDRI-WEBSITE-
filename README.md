# ANDRI GALERI + MAILTEMP

Website galeri privat bergaya dark premium dengan:
- Penyimpanan foto, video, musik, dan file di browser
- Catatan lokal
- MailTemp inbox menggunakan API Mail.tm melalui Vercel Functions
- Desain responsif untuk HP

## Menjalankan

1. Upload semua file ini ke repository GitHub.
2. Import repository tersebut ke Vercel.
3. Deploy.
4. Tidak perlu menaruh API key di frontend atau GitHub.

Catatan:
Mail.tm adalah layanan email sementara. Website menampilkan status aktif selama mailbox dan token masih valid. Durasi mailbox mengikuti kebijakan provider, jadi tidak dapat dijamin permanen selamanya.
